# Dados pessoais e credenciais

Não envie senhas, chaves de API, tokens, cookies, códigos de autenticação,
configurações de contas ou gravações privadas para issues ou pull requests.
Revise logs e relatórios antes de publicar. Use exemplos sintéticos para testes.
Se descobrir uma chave exposta, revogue-a no serviço de origem; removê-la de um
commit não apaga cópias nem o histórico. Não publique dados de terceiros.

Esta central não inclui os dados pessoais ou modelos locais do desenvolvedor.
Isso não garante que um relatório enviado posteriormente esteja livre de dados
sensíveis: cada envio precisa ser revisado.
